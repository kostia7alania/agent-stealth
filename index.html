3. Как сайты палят популярные ИИ-браузеры и MCP в 2026 году

Матрица детекта ИИ-агентов и способы лечения
Инструмент / Агент На чём палится (почему Tinder / Cloudflare разлогинивает) Как сделать беспалевным
OpenAI Codex / Operator (Chrome Attach) Аттач через chrome.debugger включает Runtime.enable + меняет иконку вкладки / инжектит индикатор в DOM. Антифрод-heartbeat (DataDome/Tinder) ловит сериализацию console.debug(Error) и мутацию <head>, мгновенно отзывая сессию (401 Logout). Не подключать расширение с мутацией иконки к живым авторизованным вкладкам; использовать подключение по --remote-debugging-port=9222 без Runtime.enable (изолированный ExecutionContext).
Claude in Chrome / Computer Use Клики без предварительной траектории pointermove, точное попадание в геометрический центр (x + w/2, y + h/2), удержание кнопки <5 мс, работа в расфокусированной вкладке (hasFocus=false). Добавлять кривую Безье (12-25 событий pointermove), Гауссов сдвиг от центра кнопки (30%-70%), задержку pointerdown -> pointerup 60-140 мс.
Kimi (Kimi WebBridge / Kimi-CU) Локальный мост CDP / WebSocket при стандартном инжекте триггерит V8 Runtime.consoleAPICalled и оставляет равномерный интервал нажатий клавиш без естественного джиттера. Запускать через чистый профиль Chrome с --disable-blink-features=AutomationControlled и рандомизировать тайминги ввода (65-190 мс).
Playwright MCP / Chrome DevTools MCP Флаг navigator.webdriver=true (при запуске с --enable-automation), утечка Runtime.enable на console.table(Proxy), а также screenY === clientY при Input.dispatchMouseEvent. Использовать patchright или rebrowser-patches (REBROWSER_PATCHES_RUNTIME_FIX_MODE=addBinding) либо браузер camoufox.
agent-browser / Browser-Use / Stagehand Инжект визуальных рамок [data-browser-use] / [data-stagehand] в основной DOM и слепое нажатие на невидимые человеку AXTree Honeypot кнопки по ссылкам @eN. Отключить DOM-хайлайты на защищённых доменах и проверять видимость элемента (width >= 6, opacity > 0.1, не clip-path: inset(50%)) перед кликом по @eN.

4. Установить навык беспалевности (Agent Skill)

Подключите навык agent-stealth в Codex, Claude Code, Cursor, Kimi или Antigravity одной командой:

1. Установка через Vercel Skills CLI (Codex, Claude Code, Cursor, OpenClaw) 
npx skills add kostia7alania/agent-stealth --skill agent-stealth
2. Чистый запуск Chrome без флагов автоматизации (macOS) 
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.chrome-stealth-profile" \
  --disable-blink-features=AutomationControlled \
  --no-first-run \
  --no-default-browser-check
3. Конфиг Playwright MCP со скрытием CDP Runtime.enable 
{
  "mcpServers": {
    "playwright-stealth": {
      "command": "npx",
      "args": ["@playwright/mcp@latest", "--cdp-endpoint", "http://127.0.0.1:9222"],
      "env": {
        "REBROWSER_PATCHES_RUNTIME_FIX_MODE": "addBinding"
      }
    }
  }
}
